# PC Hardware Profile

A living record of this PC's hardware, maintenance, thermals, benchmarks, upgrade history, and future office setup plans.

## Current status

- **Overall:** Strong AM5 gaming/workstation PC; no immediate CPU/GPU replacement needed.
- **Bluetooth repair:** Completed. A Wavlink PCIe adapter using Intel AX210 Wi-Fi 6E / Bluetooth is installed and working correctly. The old Intel AC 3168 path is disabled/bypassed.
- **Cleaning:** Major dust cleaning completed with an air duster.
- **CPU health:** Ryzen 5 7600X scored 3211 pts in Cinebench 2026 multi-core, matching Cinebench's identical-CPU reference. Peak Tctl/Tdie was 82.6 C with no thermal throttling. No CPU repaste or AIO replacement is currently justified.
- **GPU health:** RTX 4070 Ti scored 79,915 pts in Cinebench 2026, matching Cinebench's identical-GPU reference. Peak core/hotspot/memory-junction temperatures were 54.7 / 61.2 / 62.0 C. No GPU repaste or disassembly is currently justified.
- **RAM:** 32 GB DDR5 is currently sufficient; do not buy more RAM unless real workloads show memory pressure.
